# FRAME Screenshot Studio

By **zemci**. A fullscreen screenshot gallery and editor, written in Rust.

**F6** opens the studio. **F8** captures. Change these keys in Settings.

Draw consecutive frames and shapes, write text directly on the image, move and resize annotations, crop, zoom, manage layers, undo/redo and rename in the gallery. Tools stay selected until you change or deselect them.

Copy edited images, save as PNG/JPEG and optionally copy every capture to the clipboard. Configure preview, flash, shutter sound and capture on confirmed death. Death capture reads one image after GD confirms death, with no continuous screenshot caching.

One mod includes **English / Français**. English is the default; choose your language in **Settings > Interface and files**. Closed studio passes game input through. Pause the game before editing.

Windows x64, GD 2.2081, Geode 5.10.1. [Source and support](https://github.com/SamuelFelix46/FRAME-Screenshot-GeodeGD).
